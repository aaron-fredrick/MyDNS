# MyDNS Light Theme

Canonical light-theme tokens from the My Systems Brand Profile.

| Token | Hex | Use |
|---|---|---|
| `color.bg.0` | `#F8FAFC` | Main application background |
| `color.bg.1` | `#FFFFFF` | Primary surfaces |
| `color.bg.2` | `#F1F5F9` | Secondary/elevated surfaces |
| `color.border` | `#D9E1EA` | Borders and dividers |
| `color.text.primary` | `#111827` | Main text |
| `color.text.secondary` | `#475569` | Supporting text |
| `color.text.muted` | `#64748B` | Metadata and low-priority text |
| `color.brand.primary` | `#315EDE` | Main brand interaction |
| `color.brand.hover` | `#2447A8` | Hover/focus |
| `color.brand.deep` | `#2447A8` | Strong emphasis / active states |
| `color.brand.soft` | `#5D7FE8` | Secondary accents / hover support |
| `color.accent` | `#0D9F82` | Secondary brand accent |
| `color.success` | `#059669` | Healthy / successful state |
| `color.warning` | `#D97706` | Warning state |
| `color.error` | `#DC2626` | Error / failure state |
| `color.info` | `#2563EB` | Informational state |
| `color.neutral` | `#64748B` | Neutral state |

## Usage

Use the semantic token names in frontend components. Do not spread raw hex values through the application.

The light palette is a first-class theme rather than a simple inversion of the dark palette.
