# MyDNS Dark Theme

Canonical dark-theme tokens from the My Systems Brand Profile.

| Token | Hex | Use |
|---|---|---|
| `color.bg.0` | `#0B0F14` | Main application background |
| `color.bg.1` | `#111720` | Secondary surfaces |
| `color.bg.2` | `#18212C` | Cards, panels, elevated surfaces |
| `color.border` | `#283444` | Borders and dividers |
| `color.text.primary` | `#F1F5F9` | Main text |
| `color.text.secondary` | `#A8B3C2` | Supporting text |
| `color.text.muted` | `#718096` | Metadata and low-priority text |
| `color.brand.primary` | `#5B8CFF` | Main brand interaction |
| `color.brand.hover` | `#7AA3FF` | Hover/focus |
| `color.brand.deep` | `#3B5FCC` | Strong emphasis / active states |
| `color.brand.soft` | `#8FAFFF` | Secondary accents / hover support |
| `color.accent` | `#22C7A5` | Secondary brand accent |
| `color.success` | `#34D399` | Healthy / successful state |
| `color.warning` | `#FBBF24` | Warning state |
| `color.error` | `#F87171` | Error / failure state |
| `color.info` | `#60A5FA` | Informational state |
| `color.neutral` | `#94A3B8` | Neutral state |

## Usage

Use the semantic token names in frontend components. Do not spread raw hex values through the application.

Dark mode is the primary MyDNS visual environment, but it is not the only supported theme.
